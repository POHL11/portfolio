ap04.log
# Résumé
Séparation des services de la plateforme Moodle sur deux serveurs dédiés (serveur web et serveur de base de données), chacun placé dans sa propre zone réseau, puis mise en place des règles de pare-feu (pfSense) pour n'autoriser que les flux strictement nécessaires entre ces zones.
# Architecture
  • OPT1 : serveur web (192.168.10.2)
  • OPT2 : serveur de base de données (192.168.20.2)
  • LAN : réseau d'administration
  • WAN : accès depuis internet
# Règles pare-feu mises en place
  • WAN → OPT1 : seul le port 80 (HTTP) est autorisé vers le serveur web, redirigé par une règle de NAT (Port Forward) vers 192.168.10.2:80 ; tout le reste du trafic entrant est bloqué.
  • OPT1 → OPT2 : le serveur web est autorisé à joindre le serveur de base de données sur le port 3306 (MySQL), ainsi qu'un hôte du LAN (192.168.2.199) sur le port 445 ; l'accès du serveur web vers le LAN est bloqué.
  • OPT2 → LAN : le serveur de base de données est autorisé à joindre le même hôte du LAN sur le port 445 ; l'accès vers le LAN et vers OPT1 est bloqué.
  • LAN : autorisé à sortir vers les autres réseaux pour l'administration, mais bloqué en direct vers OPT2 (le serveur de base de données n'est accessible que via le serveur web).
# Objectif de sécurité
Isoler le serveur de base de données du reste du réseau : il n'est joignable que depuis le serveur web, lui-même seul exposé sur internet via le port 80. Chaque zone (WAN, OPT1, OPT2, LAN) ne peut communiquer qu'avec ce qui lui est strictement nécessaire.

# Contexte
Stage réalisé au sein du service informatique de Foussier, une entreprise qui gère plusieurs sites et agences. Il m'a permis de découvrir l'environnement de l'entreprise et de participer aux missions quotidiennes de l'équipe.
# Déploiement de matériel
Configuration et déploiement de postes fixes et portables, d'écrans, de téléphones et de cartes SIM pour PC. Installation d'imprimantes et de copieurs (CUPS, serveur d'impression, mise à jour des pilotes), préparation de boîtiers 4G, remise de PC dans le domaine et création d'une clé Windows 11 avec Rufus.
# Administration
Utilisation d'Active Directory (création d'utilisateurs, rangement des postes dans les bonnes UO, mots de passe, accès aux dossiers du serveur en lecture ou lecture/écriture), de MEDC pour la gestion des téléphones et de GLPI pour le suivi des actifs et des tickets. Déblocage de PC chiffrés avec BitLocker.
# Support utilisateurs
Passage sur la boucle de support : réinitialisation de mots de passe Microsoft 365, mises à jour logicielles, problèmes de réseau, d'imprimantes et de Teams, avec TeamViewer et KeePass. Vérification des mails suspects signalés par les utilisateurs via AvantdeCliquer.
# Remplacement des platines
Préparation de PC fixes pour remplacer les platines des magasins et transfert des données des utilisateurs. J'ai rédigé une procédure pour que chacun puisse sauvegarder ses données avant le changement de poste.
# Logistique et stock
Préparation et envoi quotidien des colis vers les agences, réception du matériel, rangement du stock et déplacement au magasin du Mans pour intervenir sur des imprimantes.
